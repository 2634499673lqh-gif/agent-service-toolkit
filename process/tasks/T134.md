# T134 — Conditional critical/high blocker remediation

**Model:** STANDARD/STRONG; **Review:** Focused revalidation; **Depends:** conditional activation by T133 or T135.

This is a remediation window, not a normal static-DAG dependency. Activate only when a finding includes severity, concrete repository evidence, affected contract, minimum required correction, and focused validation. Apply the minimum fix, then return to the affected task/review surface.

**Acceptance/evidence:** no speculative implementation when no qualifying blocker exists; an activated fix has focused implementation validation and independent focused re-review. Do not create a T134 ↔ T135 dependency cycle.
