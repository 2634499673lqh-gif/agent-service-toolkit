# T061 — Capability contract and explicit dispatch

Depends on: T060. Implementation Model: STANDARD; Review: Strong Review.

## Goal
Implement one typed capability protocol and explicit in-process dispatch adapter consumed by the existing Executor.

## Scope
Reuse `ExecutionResult` and `RuntimeFailure`; validate capability name, input bounds, output bounds, and sanitized error fields. Unknown capability and malformed output are terminal normalized failures. No registry, plugin loading, provider client, or authorization context in AgentState.

## Evidence
Unit/contract tests for success, unknown capability, malformed output, bounded output, sanitized errors, and deterministic dispatch. Runtime integration proves retry/replan consume the existing budgets and remain in the same TaskRun.

## Strong Review focus
Contract compatibility with ADR-006 and fail-closed handling of untrusted capability output.
