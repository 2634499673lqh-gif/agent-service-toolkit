## Matrix

Authentication: valid, missing, malformed, invalid, expired, revoked, inactive user/membership/organization, generic login failure; active session + active user + active membership + inactive organization returns 401, no CurrentPrincipal, and no protected-resource access.

Bootstrap: hidden prompt, no plaintext CLI/password argument, successful atomic creation, exact repeat no-op without duplicate or password reset, partial/conflicting fail-closed, intermediate failure rollback, plaintext/hash absent from logs.

Tenant: same-tenant allow, cross-tenant 404, forged user/org/role ignored, `/threads` and AG-UI identity attempts.

Role/approval: allowed owner/admin/member operations, denied role, unauthorized approval, duplicate decision.

Secrets: password absent from responses, hash/token absent from responses/logs, legacy secret redaction.

Persistence: fresh DB, existing upgrade, revision metadata, LangGraph coexistence, development/test one-revision downgrade verification, production forward-only policy and separately reviewed destructive downgrade, rollback on error, independent sessions, cleanup.
