# T026 — Authentication and tenant negative tests

Implementation Model: LOW_COST  
Review Model: STRONG_REVIEW_REQUIRED

Tests-only hardening for the approved Phase 2 behavior. Do not alter production behavior to make tests pass.

## Depends on

T023–T025.

## Required matrix

Valid login; wrong/unknown/inactive identity; malformed/expired/revoked credential; forged user/org/role claims; caller-supplied `user_id` and `/threads`/AG-UI identity attempts; same-tenant allow; cross-tenant deny/404; unauthorized approval/resource lookup; duplicate decision; rollback/session cleanup; secret/hash/token redaction.

Run focused auth/API tests, then full `uv run pytest`, `uv run ruff format --check`, `uv run ruff check`, `uv run pyrefly check`, and applicable documentation checks.

Review Model: STRONG_REVIEW_REQUIRED. Include missing credential, wrong role, forged user_id/organization_id ignored, and password/hash/token absent from both response and logs.

The negative matrix includes missing credential, wrong role, forged user_id/organization_id ignored, and password/hash/token absent from responses and logs.
