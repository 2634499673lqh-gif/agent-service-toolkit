# T062 — First deterministic read-only capability

Depends on: T061. Implementation Model: LOW_COST/STANDARD; Review: Strong Review.

## Goal
Add exactly one deterministic, read-only, in-process capability that demonstrates the boundary without external effects.

## Scope
Use fixed input data or the existing task snapshot; no network, filesystem, shell, credentials, provider, or tenant data access. Output is bounded and replay-safe.

## Evidence
Exact fixture outputs, repeated invocation equality, and runtime success/failure integration. No real infrastructure required.

## Strong Review focus
No hidden side effect, no authority escalation, and no claim of exactly-once execution.
