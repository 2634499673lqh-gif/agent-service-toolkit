# T139 — GeoChange LLM Parameter Authority

**Model:** STANDARD/STRONG  **Review:** Strong Review  **Depends:** T138

**Scope/files:** `src/geochange/models.py`, `src/geochange/llm.py`,
`src/geochange/runtime_caps.py`, and the existing planner/context boundary only
if required. Add a deterministic server extractor that runs on original text
before LLM merge. It recognizes only `cloud_threshold` and
`decline_threshold`, with the supported parameter phrase plus decimal syntax;
`30%` and `-0.15` are valid examples. It returns trusted `user_text` evidence
or `explicit: false`. Fixed defaults are cloud `30.0` and decline `-0.2`.
Valid user text values beat defaults; model numeric values never beat either.

**Acceptance/evidence:** explicit cloud `30%` and decline `-0.15` are honored;
omitted values use defaults; semantic “significant decline” does not create a
numeric authority; malformed, out-of-range, unsupported-unit, and conflicting
repeated values reject deterministically; model-provided explicitness/numbers
cannot override extraction; mode remains server-owned. Focused tests cover all
cases and ensure no secrets or tenant authority enter checkpoint state.

**Stop:** stop if the existing schema cannot preserve explicitness without a
contract change requiring ADR-013 revision; do not add a generic parser or
provider registry. **Deferred:** BYOK, arbitrary parameters, new modes.
