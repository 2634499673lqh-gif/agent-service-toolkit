# T122 — Background worker integration

**Status:** Implementation in progress under ADR-015; independent Strong Review pending.

Implement the smallest PostgreSQL-backed durable TaskRun worker. Reuse the
existing TaskRun lifecycle and LangGraph checkpoint identity. Add only the
persisted lease/attempt fields, `SKIP LOCKED` claim, heartbeat, stale reclaim,
bounded retry and Compose startup wiring required by ADR-015. Keep the existing
process-local dispatch fallback for SQLite and legacy tests. Do not add Redis,
Kafka, autoscaling, generic queue abstractions, or exactly-once claims.
