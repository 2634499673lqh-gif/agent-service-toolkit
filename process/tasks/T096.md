# T096 — Deterministic cost estimator

Depends on: T095. Review: Strong Review.

## Objective

Calculate an informational estimate from explicit bounded configuration and
known usage.

## Required contract

Pricing is an in-process table keyed by (provider, model, version), with
bounded non-blank identifiers, a currency string of at most 8 characters, and
non-negative Decimal input/output prices per 1,000 tokens (at most 12 integer
and 6 fractional digits). The pure estimator accepts only complete known usage
and a matching entry.

Compute input plus output price, round to six fractional places with
ROUND_HALF_UP, and return a fixed-scale decimal string plus currency. Token
counts use T095 bounds; a result above 10^18 currency units is overflow.
Missing price, unsupported model, unavailable/partial usage, and overflow
return an explicit unknown result with exactly one of missing_price,
unsupported_model, usage_unavailable, or overflow. Unknown is never numeric
zero and the result is never billing truth.

## Acceptance and negative evidence

Deterministic table-driven tests cover exact arithmetic, half-up rounding,
bounds, missing/unsupported price, unavailable/partial usage, and overflow. No
network or remote price lookup is permitted.

## Documentation and checks

Update observability documentation and run focused tests, static checks, and
git diff --check during implementation.
