# T024 — Current-user dependency

Implementation Model: STANDARD  
Review Model: STRONG_REVIEW_REQUIRED

Create a typed FastAPI dependency that resolves the current authenticated user and server-derived organization context from the approved credential mechanism.

## Depends on

T023.

## Acceptance

- Missing, malformed, expired, revoked and inactive credentials fail with the documented status/envelope.
- Dependency never trusts request `user_id`, `organization_id`, role claims without server validation, or AG-UI/client configurable identity.
- Context is request-scoped and typed; DB sessions follow the approved lifecycle and always close/rollback.
- Legacy `AUTH_SECRET` remains explicitly separated from this identity dependency.

Implementation must consume the approved async session lifecycle and never place ORM sessions in LangGraph AgentState.
