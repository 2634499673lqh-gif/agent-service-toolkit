# T024 — CurrentPrincipal FastAPI dependency

Implementation Model: STANDARD  
Review Model: STRONG_REVIEW_REQUIRED

Create the typed request-scoped dependency consuming T023 opaque sessions.

## Depends on

T023.

## Scope

`CurrentPrincipal` contains `user_id`, `membership_id`, `organization_id`, `role`, and `session_id`; all values are server-derived by token-hash lookup plus fresh database checks on every request: session exists, not revoked, not expired, user active, membership active, and organization active. Any failure returns the generic 401 invalid/inactive credential; no CurrentPrincipal is constructed and protected resources are not accessed. Organization ID and role come from the current verified Membership/Organization rows, never cached session state or claims. Acquire/close the async session and rollback on exceptions. Never place SQLAlchemy sessions in LangGraph AgentState.

## Verification

Missing/malformed/invalid/expired/revoked/inactive user/inactive membership/inactive organization credentials return one generic 401 envelope. Include an explicit test for active session + active user + active membership + inactive organization: 401, no CurrentPrincipal, no protected-resource access. Prove request `user_id`, `organization_id`, role claims, `/threads`, and AG-UI identity cannot select scope. Keep `AUTH_SECRET` separate.
