# T103 — Deterministic metrics calculation

**Model:** LOW_COST; **Review:** Strong Review; **Depends:** T102.

Implement pure functions for `pass_rate`, `recovery_success`, `approval_compliance`, and `evidence_completeness` over typed case results and case contracts. Every metric uses `{status, numerator, denominator, rate}` with four fixed decimal places and `Decimal` `ROUND_HALF_UP`; denominator zero is exactly `not_applicable` with `0/0/null`. Preserve the distinction between per-run metrics and cross-run comparison; incomparable runs emit no deltas and are not metric failures.

**Acceptance:** table-driven tests cover pass/fail/error, missing or partial evidence, recovery/approval tags, incomparable inputs, and empty denominators; values and serialized rates are deterministic and bounded.
