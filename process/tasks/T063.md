# T063 — Sanitized ContextEnvelope and builder

Depends on: T060, T061. Implementation Model: STANDARD; Review: Strong Review.

## Goal
Define and build the minimum typed context passed to capabilities.

## Scope
Context includes task input, current PlanStep, selected bounded capability inputs, and provenance labels. Deterministic selection and size limits are required. Do not add memory, organization knowledge, generic context bus, or persistence.

## Evidence
Schema/contract tests, provenance and budget tests, authority/secret exclusion tests, and checkpoint serialization tests proving only approved context fields appear in AgentState.

## Strong Review focus
Separation of business authority, runtime state, task data, capability context, outputs, and secrets.
