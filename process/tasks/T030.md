# T030 — Task domain and lifecycle architecture

Implementation Model: STRONG; Review: Planning Strong Review (single architecture gate)

## Scope

Planning only. The approved review accepts ADR-005, freezes Task/TaskRun authority, lifecycle, persistence-only cancellation, active-run invariants, API security semantics, and the executable DAG. T030 performs no second design freeze, schema, migration, runtime code, or tests. After approval ADR-005 is Accepted and T031 starts production implementation.
