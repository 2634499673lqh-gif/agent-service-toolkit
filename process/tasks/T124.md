# T124 — Liveness and readiness endpoints

**Model:** STANDARD; **Review:** Strong Review; **Depends:** T120, T121.

Implement unauthenticated `/health/live` and `/health/ready`. Liveness performs no dependency
query. Readiness requires completed startup and bounded PostgreSQL `SELECT 1`, plus configured
LangGraph persistence readiness; it excludes Langfuse/LLM. Keep compatibility behavior explicit.

**Evidence:** startup-failure, DB-down, configured/unconfigured backend, timeout, and Compose
health-check tests with fixed safe responses.
