# T022A — Membership model, role enum and active organization

Implementation Model: STANDARD  
Review Model: STRONG_REVIEW_REQUIRED

Mandatory bounded Membership subtask created by T020 because V1 selects User–Organization many-to-many. Do not fold it into an unreviewed T022 implementation.

## Depends on

T020, T021, and T022.

## Scope

Add `memberships` with UUID4 `id`, `user_id`, `organization_id`, constrained role enum `owner|admin|member`, `is_active`, UTC `created_at`/`updated_at`, unique `(user_id, organization_id)`, explicit indexes, and non-destructive foreign keys. A user may have multiple organizations but a session binds exactly one active membership; inactive user, organization, or membership cannot become principal. Repository methods require server-derived scope.

## Verification

Test duplicate membership, role constraint, active/inactive membership, one session/one active organization, cross-tenant filtering, fresh/existing upgrade, revision metadata, LangGraph coexistence, downgrade policy, and independent transactions.

## Forbidden

No login/token issuance, role helper, client-selected organization, public registration, LangGraph table changes, or `AUTH_SECRET` changes.
