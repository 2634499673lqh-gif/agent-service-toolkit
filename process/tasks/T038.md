# T038 — TaskRun start/inspect API

Depends on: T037.

Add tenant-scoped TaskRun start/inspect integration without invoking an LLM. Start is allowed only from DRAFT or FAILED and rejects QUEUED/RUNNING/SUCCEEDED/CANCELLED according to ADR-005. Preserve transactional run numbering and one-active-run safety. No application-level idempotency contract or external side effect.
