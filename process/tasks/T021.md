# T021 — SQLAlchemy foundation, Organization model and migration

Implementation Model: STANDARD  
Review Model: STRONG_REVIEW_REQUIRED

Implement only the Organization model and approved persistence foundation from ADR-004. No login, User, Membership, role policy, authorization dependency, or public registration.

## Depends on

T020 accepted ADR-004.

## Exact scope

Add SQLAlchemy 2.x async ORM using psycopg 3 async dialect, async sessionmaker, and an Alembic async environment. Own only schema `taskpilot` and Organization tables; never inspect, stamp, alter, or drop LangGraph tables. Production runs `alembic upgrade head` as a release/job step; application startup does not auto-migrate.

Organization: UUID4 `id`, `name`, `is_active`, UTC `created_at`, `updated_at`; no public hard delete. Repositories require explicit tenant scope and never commit; services own commit/rollback.

## Verification

Test fresh/existing upgrades, revision metadata/version, TaskPilot/LangGraph coexistence, development-only one-revision downgrade, UTC values, constraints, rollback on error, independent sessions, and PostgreSQL-only business schema. Model-only tests are insufficient. Run focused persistence tests and required shared tests.

## Forbidden

Do not modify `src/memory/*`, LangGraph setup, `AUTH_SECRET`, upstream endpoints, or unrelated tests. Do not add SQLite business support.
