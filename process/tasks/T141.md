# T141 — Real Sentinel-2 Cached Raster Fixture and Provenance

**Model:** STANDARD  **Review:** Strong Review  **Depends:** T138

**Scope/files:** `src/geochange/raster.py`/new minimal loader or manifest module
only if necessary; bounded fixture directory under `data/geochange-fixtures/`,
manifest, acquisition/preparation script or documented command, tests, and
provenance/demo docs. Verify candidate scenes against Earth Search before
freezing IDs; obtain real Red/NIR pixels for the bounded Wuhan East Lake AOI.

**Acceptance/evidence:** two real scenes, compact format, documented maximum
size and checksum, CRS/resolution/dimensions/AOI/assets/fixture version in a
manifest, reproducible preparation, clean repository hygiene, no synthetic
arrays in the supported fixture, and tests reject checksum/metadata mismatch.

**Stop:** stop if licensing/access, format support, or size cannot satisfy the
bound; revise the fixture strategy in ADR-013 before adding binaries. **Deferred:**
large assets and production-scale remote COG processing.
