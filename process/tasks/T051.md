# T051 — Phase 4 Final Audit

Depends on: T040–T050. Implementation Model: STRONG; Review: Strong Review; read-only.

## Objective and scope

Collect evidence that implementation conforms to accepted ADR-006/T040: AgentState serialization, planner validation, deterministic executor, verifier PASS/FAIL, classification, bounded retry/replan success/exhaustion, T035 TaskRun lifecycle, tenant/security and concurrency regression, checkpoint/resume, persistence ownership, corruption fail-closed behavior, and deferred-scope audit. Do not implement or redesign.

## Acceptance / evidence

Record accepted ADR/T040 compliance, PostgreSQL/integration results, full `pytest`, Ruff, Pyrefly, `uv lock --check`, Alembic/import checks, documentation reconciliation, and explicit absence of TaskStep ORM/migration/API, new HTTP endpoint, worker, HITL, HTTP idempotency, and real external side effects. Any gap blocks the gate and becomes a follow-up task. Update `process/PROGRESS_LOG.md`; no Codex commit/push.

Mandatory evidence also includes the exact AgentState initialization/mutation
table; Plan/PlanStep bounds and one-repair route; ExecutionResult and
VerificationResult contracts; classifier enum/routing table; retry and replan
counter transition/exhaustion and termination proof; trusted runtime service
tenant validation; same-TaskRun retry; concurrent resume duplicate-work
invariant; repeated-resume latest-checkpoint behavior; terminal-resume
rejection; cancellation and terminal-completion races; missing/corrupt
checkpoint fail-closed races; fresh PostgreSQL state assertions; and explicit
absence of any exactly-once runtime claim.
