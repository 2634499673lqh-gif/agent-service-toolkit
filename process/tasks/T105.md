# T105 — Human-readable Evaluation report

**Model:** LOW_COST; **Review:** Strong Review; **Depends:** T104.

Render deterministic Markdown and/or console output from the machine-readable report only. Preserve canonical case ordering, the four metric names and fixed rates, failure codes, runner status, and incomparable comparison reason. Do not create a second source of truth or expose prohibited payloads.

**Acceptance:** golden output tests prove derivation, stable ordering, bounded failure text, explicit `not_applicable`, and no secret/provider/checkpoint/authorization leakage.
