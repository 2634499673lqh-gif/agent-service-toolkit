# T119 — Tenant-scoped TaskRun list HTTP API

**Model:** LOW_COST; **Review:** Strong Review; **Depends:** T110.

Expose GET `/api/v1/tasks/{task_id}/runs` using the existing tenant-scoped repository and TaskRunResponse ordered by run number/id. Preserve 401/404 and lifecycle behavior; no pagination, latest pointer, TaskStep or runtime endpoint.

**Acceptance:** PostgreSQL/API tests cover ordering, empty list, roles, foreign/missing 404, unauthenticated 401 and no cross-tenant leakage; no migration/dependency change.
