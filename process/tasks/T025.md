# T025 — Central tenant authorization helper

Implementation Model: STANDARD  
Review Model: STRONG_REVIEW_REQUIRED

Implement the single server-side policy boundary frozen by ADR-004.

## Depends on

T024.

## Scope

Provide `require_authenticated`, `require_active_membership`, `require_role(roles)`, and `require_resource_tenant(resource_organization_id)`. Future repositories accept server-derived organization scope and add explicit tenant predicates. Approval reads/decisions require active owner/admin membership; duplicate decisions are idempotently rejected.

## Verification

Same-tenant allow; cross-tenant/nonexistent lookup 404; inactive/non-member/forged tenant 404; in-tenant insufficient role 403; forged caller IDs ignored; unauthorized approval denied. Run full pytest at this gate.

## Forbidden

No endpoint-specific cross-tenant semantics, enterprise policy engine, client role trust, or LangGraph state/session coupling.
