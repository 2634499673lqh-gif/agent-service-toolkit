# T106 — CI cheap smoke Evaluation

**Model:** STANDARD; **Review:** Strong Review; **Depends:** T101, T102, T103, T104.

Add the default-CI smoke command for the three cheap cases `deterministic.fixture_baseline`, `recovery.retry_then_pass`, and `approval.l2_requires_approval`. It uses deterministic fixtures and mocked providers, exits non-zero on runner `error`/`partial`, failed cases, or `incomparable` comparison, and publishes the bounded JSON artifact through the existing CI convention when available. No live model, network, database, or new production capability.

**Acceptance:** local and CI invocation are documented and tested; smoke/full-suite distinction, exact failure semantics, and bounded artifact behavior are explicit.
