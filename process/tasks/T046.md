# T046 — Verifier node

Depends on: T045. Implementation Model: STANDARD; Review: Strong Review.

## Objective and scope

Implement the verifier node against the deterministic execution result and frozen criteria, returning only the T045 contract. PASS advances; FAIL enters the T047 classifier path. Do not add Task/TaskRun states, approvals, or a generic evaluation platform.

## Acceptance / security / transaction / tests

Deterministic PASS and FAIL cases, malformed output, and evidence-boundary tests pass. No direct status mutation; no transaction spans model/runtime execution. Update docs/progress; no Codex commit/push.

## Governance

Affected layer: verifier node. Tenant and role authority remain outside verifier output. Required tests are deterministic PASS/FAIL cases; no PostgreSQL evidence is required. Strong Review is required.

## Frozen contract

The node returns T045 exactly. Invalid structured output receives one repair
attempt; a second invalid result is terminal normalized
`verifier_output_invalid`. PASS routes to runtime success. FAIL routes to T047
and can replan only when the classifier explicitly returns REPLAN.
