# T125 — Docker Compose hardening

**Model:** STANDARD; **Review:** Strong Review; **Depends:** T123, T124.

Harden the supported local/demo Compose stack: migration ordering, readiness-gated dependencies,
health checks, restart/stop behavior, named volume and non-secret defaults, image file coverage,
and bounded logs/resources where repository conventions support them. No worker or Redis.

**Evidence:** `docker compose config`, clean disposable startup, migration/readiness/restart,
service and UI health, and no secret interpolation in committed config.
