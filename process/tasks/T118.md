# T118 — AuthService-backed login/session/logout HTTP API

**Model:** STANDARD/STRONG; **Review:** Strong Review; **Depends:** T110.

Implement ADR-011 §4 login, current session and logout routes reusing AuthService/CurrentPrincipal with service-owned commit/rollback. Preserve generic 401, selection without token, no-store, safe 503 and legacy AUTH_SECRET behavior. No schema, JWT, cookies, refresh tokens, registration or role changes.

**Acceptance:** real PostgreSQL tests cover issuance, selection, revocation, rollback, duplicate logout, freshness, malformed/unknown credentials and secret-safe logs/responses; route is outside legacy bearer dependency.
