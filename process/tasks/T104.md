# T104 — Machine-readable Evaluation report

**Model:** LOW_COST; **Review:** Strong Review; **Depends:** T102, T103.

Emit the exact `taskpilot.eval.report/v1` contract frozen in ADR-010: required top-level `schema`, `suite_id`, `suite_version`, `runner_status`, `cases`, `metrics`, and `comparison`; five-case bounds; case status/failure-code invariants; four always-present metrics; always-present comparison status/reason; canonical sorted-key compact UTF-8 JSON with one trailing newline; and the 32 KiB artifact limit. Use no timestamps or run UUIDs and exclude secrets, provider/context payloads, checkpoints, ORM/session objects, and authorization objects. When the bound would be exceeded, emit no oversized artifact and return `report_size_exceeded`.

**Acceptance:** schema/version, deterministic ordering, metric shape/precision, comparison mismatch reasons, absent-vs-empty rules, canonical encoding, size failure, and redaction are tested.
