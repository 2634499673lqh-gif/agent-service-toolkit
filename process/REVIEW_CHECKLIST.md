# Review Checklist

Before accepting a Codex task:

- [ ] Scope matches the task.
- [ ] No unrelated framework/refactor changes.
- [ ] Tests actually ran.
- [ ] Negative/error cases included.
- [ ] Tenant authorization checked.
- [ ] No secrets/log leakage.
- [ ] State transitions valid.
- [ ] Retry loops bounded.
- [ ] Side effects idempotent.
- [ ] Approval cannot be bypassed.
- [ ] Docs updated only where needed.
- [ ] Progress log updated.
- [ ] I can name the 3 most important changed files.
- [ ] I understand what the change does at a high level.
