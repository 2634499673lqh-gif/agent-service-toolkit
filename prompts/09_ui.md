# Phase 9 Prompt — Product UI

## Goal

Provide a usable V1 interface without destabilizing backend.

## Decision

First assess existing Streamlit.

If it can support the demo, improve it before introducing Next.js.

Only add Next.js/React when:
- backend APIs are stable
- auth flow is defined
- task/trace/approval APIs are stable

## Required screens

- login/current user
- create task
- list tasks
- task/run detail
- step timeline
- trace/tool view
- approval queue/detail
- result
- optional evaluation summary

## Constraints

- UI is not a security boundary
- do not duplicate business state machine in frontend
- sanitize rendered tool/document content
- show loading/error states
- do not expose secrets/raw internal prompts by default

Add UI tests appropriate to framework and update user guide.
