# Glossary

- LLM: Large Language Model.
- Agent: model-centered task executor that can reason/use tools across steps.
- Harness: runtime/control environment around an Agent loop.
- Skill: reusable capability/SOP package.
- Tool: callable deterministic or external capability.
- LangGraph: graph/state-oriented Agent orchestration framework.
- State: data carried through execution.
- Checkpoint: persisted execution state allowing recovery/resume.
- HITL: Human-in-the-loop.
- RAG: Retrieval-Augmented Generation.
- Tenant: isolated organization/customer scope.
- RBAC: Role-Based Access Control.
- Idempotency: repeated request does not repeat the logical side effect.
- Trace: structured execution history.
- Span: timed operation inside a trace.
- Eval: repeatable evaluation.
- Golden case: manually or deterministically trusted expected case.
